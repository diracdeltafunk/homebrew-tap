# diracdeltafunk/homebrew-tap

Homebrew formulae for [bibers](https://github.com/diracdeltafunk/bibe-rs), a fast, biber-compatible bibliography processor for biblatex.

```sh
brew install diracdeltafunk/tap/bibers
```

This installs the prebuilt release binary (macOS universal, Linux x86_64 and arm64). To make latexmk use bibers instead of biber, add `$biber = 'bibers %O %S';` to `~/.latexmkrc`; see the [bibe-rs README](https://github.com/diracdeltafunk/bibe-rs#using-bibers-instead-of-biber) for other tools.

`Formula/bibers.rb` is generated by [`tools/release/homebrew.py`](https://github.com/diracdeltafunk/bibe-rs/blob/main/tools/release/homebrew.py) and updated automatically when a bibers release is published. Please report problems in the [bibe-rs issue tracker](https://github.com/diracdeltafunk/bibe-rs/issues).
